# 🐷 꿀꿀 가계부

DB도, 회원가입도 필요 없는 귀여운 한 장짜리 가계부예요.
`index.html`을 브라우저로 열면 바로 쓸 수 있어요.

## 기능
- 수입/지출 입력 (날짜 · 분류 · 금액 · 메모)
- 월별 수입 · 지출 · 잔액 요약
- 📅 달력 보기 — 날짜를 누르면 그날 내역만 보여요
- 분류별 아이콘 (🍚 식비, 🚌 교통, 💼 월급 …)
- 분류별 지출 그래프
- CSV 내보내기

## 데이터 저장
내역은 브라우저의 localStorage에만 저장돼요.
같은 브라우저에서는 계속 남아 있지만, 다른 기기와는 공유되지 않아요.
중요한 내역은 CSV로 백업해 두세요.
