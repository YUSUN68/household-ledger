# 🐷 꿀꿀 가계부

DB도, 회원가입도 필요 없는 귀여운 한 장짜리 가계부예요.
`index.html`을 브라우저로 열면 바로 쓸 수 있어요.

## 기능
- 수입/지출 입력 (날짜 · 분류 · 금액 · 메모)
- 월별 수입 · 지출 · 잔액 요약
- 📅 달력 보기 — 날짜를 누르면 그날 내역만 보여요
- 분류별 아이콘 (🍚 식비, 🚌 교통, 💼 월급 …)
- 분류별 지출 그래프
- CSV 내보내기

## 데이터 저장
내역은 [Supabase](https://supabase.com)의 `ledger_entries` 테이블에 저장돼요.
어느 기기에서 열어도 같은 내역이 보여요.
회원 기능이 없어서 이 페이지에 들어온 사람은 누구나 내역을 보고, 추가하고, 지울 수 있어요.

예전에 브라우저(localStorage)에 저장해 둔 내역이 있으면, 처음 열 때 DB로 옮길지 물어봐요.
